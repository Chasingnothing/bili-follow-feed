# B站 只看关注

一个浏览器用户脚本，把 B 站的**关注动态流**渲染成一面**按分组组织的卡片墙**，绕开首页推荐流。

> **解决的痛点**：B 站首页是推荐流，它总推你没关注的人的视频，结果你反而看不到自己关注的人更新了什么。
> B 站的「动态」页虽然只显示关注的人，但混杂图文/转发/直播推广位，也不是卡片墙。
>
> 这个脚本给你一个只属于关注列表的页面。

---

## 它长什么样

- **按本地关注分组分板块** —— 分组和 B 站隔离，首次从 B 站导入，之后你自己管
- **B 站风格的卡片** —— 封面 + 标题 + UP 主 + 播放量 + 时长
- **图文动态**和视频并列显示（`MAJOR_TYPE_OPUS`），纯文字帖用占位封面
- 点卡片跳 B 站原视频 / 原动态页
- 已读标记、按时间/播放量排序、按类型筛选、每个板块独立的页码

**两种模式**：

| 模式 | 干什么 | 适合 |
|---|---|---|
| **模式 1 · 动态流**（默认） | 全局动态流 + 时间窗深度翻页 | 想一次看完所有关注的人的更新 |
| **模式 2 · UP 主拉取** | 按 UP 逐个拉取最新的 5 条 | 关注的人太多、动态流翻不到底 |

## 怎么用

**装好之后打开这个网址**：

```
https://www.bilibili.com/agent-feed
```

> ⚠️ **这个路径是必须的。** 脚本的 `@match` 收窄到了这一个路径 —— 其他 B 站页面**完全不加载**它。
>
> 为什么是这个路径？B 站对未知路径不重定向也不改写 URL（2026-09 实测），只在原址渲染它的 404 页。
> 我们**接管的就是那个 404 页**（用 `html.bff-active body { display: none }` 把原生内容藏起来）。
>
> 副作用：B 站 404 页上的导航也被藏了，所以页面工具栏里自带一个「返回 B站」的出口。

**首次使用**：脚本会读你的关注列表和 B 站分组，几秒钟后给出侧边栏。

> **不需要登录任何额外账号。** 脚本用的是你浏览器里已有的 B 站登录态。

---

## 需要什么

- 一个**已登录**的 B 站账号（关注列表要求登录）
- Tampermonkey（或兼容的用户脚本管理器）

**不需要**：后端、API key、额外的账号授权。

### 它不做什么

- ❌ **不取消关注、不点赞、不评论、不转发** —— 全程只用只读接口，**没有任何写操作**
- ❌ 不建后端，不往任何第三方服务器发数据
- ❌ 不索取、不上传你的 Cookie

所有数据都在你自己的浏览器里（`localStorage`，属于 `www.bilibili.com` 这个域）。

## 已知限制

| 限制 | 说明 |
|---|---|
| **没有历史库** | 只显示动态流窗口内的内容。你两周没打开，那两周的更新就看不到了（除非手动翻页） |
| **不能定时抓取** | 用户脚本只在页面打开时存在，架构上做不到 |
| **和 B 站红点是两套** | 在它里面点开视频**不会**消除 B 站首页的红点，反之亦然（因为我们从不写 B 站） |
| **「NEW」是近似** | 用时间戳比出来的，不是真正的"未读" |
| **模式 2 每个 UP 只留 5 条** | 想看更早的要去 UP 主主页 |
| **模式 2 不覆盖「未分类」** | 那几百个没归类的 UP 不在模式 2 逐个拉（这正是它的设计前提） |
| **关注列表最多导入 5000 人** | 超出会截断并提示 |
| **只在桌面 Chrome 上验证过** | Firefox / Edge / 手机端的可行性分析见 [`docs/DESIGN.md`](docs/DESIGN.md)，但**没有实测过** |

## 开发

```bash
npm install
npm run dev      # Vite 开发服务器
npm run test     # tsc --noEmit && vitest run
npm run build    # tsc --noEmit && vite build  → dist/
npm run verify   # test + build（提交前跑这个）
```

`npm test` 里带 `tsc` 是**刻意**的：这个项目有过两个只有类型检查能抓、单元测试完全抓不到的 bug。

**技术栈**：TypeScript · React 19 · Vite 8 · [vite-plugin-monkey](https://github.com/lisonge/vite-plugin-monkey) · Vitest 5

**构建产物已提交**（`dist/bili-follow-feed.user.js`），因为自动更新要用 raw 链接。
改了代码记得 `npm run build` 并一起提交，同时**升版本号** —— 否则装了的人不会收到更新。
